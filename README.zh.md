# Autojourney 技能

[English](README.md) · 中文

让你的 AI 助手（Claude、Codex、Cursor 等能执行命令的客户端）直接指挥浏览器里的 **Autojourney 插件**：在豆包、ChatGPT、Gemini、Midjourney、即梦、可灵等平台上生图、生视频、图生文，结果保存到本机。用的是你自己的会员额度，不用 API key。

**用法、例子、常见问题：https://autojourney.ai/zh/agent**

## 安装

把这句发给你的 AI 助手，它会装好技能和本机程序，再带你完成设置：

```
请按照 https://cdn.autojourney.ai/agent/install.zh.md 的指引安装 Autojourney 技能并初始化设置
```

或者用 skills 命令行（需要 Node.js）：`npx skills add autojourney/skills`

需要：要用的平台对应的 Autojourney 插件、Pro 会员、在插件设置里打开「**Agent 模式**」。支持 macOS 和 Windows。

然后直接跟助手说，比如「用豆包画一只橘猫，水彩风格，存到桌面」。
