# Autojourney skill

English · [中文](README.zh.md)

Let your AI assistant (Claude, Codex, Cursor and other clients that can run commands) drive the **Autojourney browser extensions**: generate images and videos, and describe images, on Doubao, ChatGPT, Gemini, Midjourney, Jimeng, Kling and more, saving the results to your computer. It runs on your own membership quota; no API key needed.

**Guide, examples and FAQ: https://autojourney.ai/en/agent**

## Install

Send this to your AI assistant; it installs the skill and the local program and walks you through setup:

```
Follow https://cdn.autojourney.ai/agent/install.md to install the Autojourney skill and finish the setup
```

Or with the skills CLI (needs Node.js): `npx skills add autojourney/skills`

You'll need the Autojourney extension for each platform you use, a Pro membership, and **Agent mode** switched on in the extension. macOS and Windows.

Then just ask, for example: "Draw an orange cat with Doubao, watercolor style, and save it to my desktop".
